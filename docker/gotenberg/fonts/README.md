# Licensed fonts (optional)

If the school's licence allows installing them on the server, put the
original font files here (for example `times.ttf`, `timesbd.ttf`,
`timesi.ttf`, `timesbi.ttf`, `aptos-narrow.ttf`) and rebuild the Gotenberg
image. Without them the PDF uses metric-compatible substitutes, so the line
breaks still match; the DOCX is always the canonical file.

Font files are not committed (see `.gitignore`).
